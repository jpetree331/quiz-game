# German — first words
Useful little words for your next adventure.

## What does "Danke" mean?
- [x] Thank you
- [ ] Please
- [ ] Hello
- [ ] Sorry
> Said like DAHN-kuh.

## What does "Bitte" mean?
- [x] Please (and also "you're welcome")
- [ ] Goodbye
- [ ] Yes
- [ ] Water
> One word does double duty: it is both "please" and the reply to "Danke".

## What is "der Hund"?
- [x] The dog
- [ ] The cat
- [ ] The horse
- [ ] The bird

## What is "die Katze"?
- [x] The cat

## What is "das Wasser"?
- [x] Water

## What is "das Brot"?
- [x] Bread

## What does "Guten Morgen" mean?

- [ ] Good night
- [ ] Good evening
- [ ] Good luck

## What does "Tschüss" mean?
- [x] Bye
- [ ] Cheers
- [ ] Thanks
- [ ] Excuse me
> Said like CHOOSS. Casual, for friends.

## What is "der Zug"?
- [x] The train
- [ ] The bus
- [ ] The plane
- [ ] The bicycle
> The one you are probably sitting on right now.

## You see the word "Milch" on a carton. What is inside?
- [x] Milk
- [ ] Juice
- [ ] Tea
- [ ] Water
> German nouns begin with a capital letter: die Milch.

## Which German word means "no"?
- [x] Nein
- [ ] Ja
- [ ] Bitte
- [ ] Danke
> Ja means yes; nein means no.

## What does "Guten Abend" mean?
- [x] Good evening
- [ ] Good morning
- [ ] Good luck
- [ ] Goodbye
> Abend is the German word for evening.

## Which animal is "der Vogel"?
- [x] The bird
- [ ] The fish
- [ ] The rabbit
- [ ] The horse
> Vogel means bird.

## What is "das Buch"?
- [x] The book
- [ ] The table
- [ ] The bag
- [ ] The window
> The plural is die Bücher.

## A sign points to "der Bahnhof". Where does it lead?
- [x] The railway station
- [ ] The library
- [ ] The hospital
- [ ] The airport
> Bahnhof means railway station.

## What color is "rot"?
- [x] Red
- [ ] Blue
- [ ] Green
- [ ] White
> Rot is red; blau is blue.

## Which German word means "green"?
- [x] Grün
- [ ] Gelb
- [ ] Schwarz
- [ ] Weiß
> Grün is green, while gelb is yellow.

## What number is "drei"?
- [x] Three
- [ ] Two
- [ ] Four
- [ ] Five
> Eins, zwei, drei means one, two, three.

## What number is "zehn"?
- [x] Ten
- [ ] Seven
- [ ] Twelve
- [ ] Twenty
> Zehn is ten; zwanzig is twenty.

## What does "heute" mean?
- [x] Today
- [ ] Yesterday
- [ ] Always
- [ ] Never
> Heute refers to the current day.

## What is "die Sonne"?
- [x] The sun
- [ ] The moon
- [ ] The star
- [ ] The cloud
> Sonne is the German word for sun.

## What is "der Mond"?
- [x] The moon
- [ ] The mountain
- [ ] The sea
- [ ] The forest
> Mond means moon.

## Which German word means "small"?
- [x] Klein
- [ ] Groß
- [ ] Schnell
- [ ] Alt
> Klein means small; groß means big or tall.

## What does "kalt" mean?
- [x] Cold
- [ ] Hot
- [ ] Soft
- [ ] Heavy
> Kalt means cold; warm means warm.

## What is "die Straße"?
- [x] The street
- [ ] The bridge
- [ ] The field
- [ ] The kitchen
> The letter ß represents an s sound.

## What does "links" mean in directions?
- [x] Left
- [ ] Right
- [ ] Straight ahead
- [ ] Back
> Links is left; rechts is right.

## What is "der Schlüssel"?
- [x] The key
- [ ] The door
- [ ] The chair
- [ ] The clock
> Schlüssel is the word for a key.
